## ⚙ Installation

#### Install via GIT

- Thêm repository này như một [Submodule](https://git-scm.com/book/en/v2/Git-Tools-Submodules) vào trong thư mục `Assets/HAVIGAME` của dự án.
  ```
  git submodule add https://github.com/dev-vinhnv/havigame.git Assets/HAVIGAME
  ```

#### Install via SourceTree
- Chuột phải vào menu trống để mở popup thêm [Submodule sử dụng SourceTree](https://confluence.atlassian.com/sourcetreekb/adding-a-submodule-subtree-with-sourcetree-785332086.html).
- Nhập URL `https://github.com/dev-vinhnv/havigame.git` và chọn đường dẫn đến thư mục `Assets/HAVIGAME` của dự án.
